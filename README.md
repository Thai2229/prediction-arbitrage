
# Prediction Arbitrage

A full-stack website that identifies potential arbitrage opportunities across prediction markets such as Kalshi and Polymarket. In the future, wanna add more websites to arbitrage such as BetMGM and more...

## Planned Features

- Cross-platform market price comparison
- Automated market matching
- Arbitrage profit and ROI calculations
- Trading fees and liquidity considerations
- Interactive market dashboard

## Tech Stack

- Frontend: React, Next.js, TypeScript
- Backend: Python, FastAPI
- Database: PostgreSQL
- Version Control: Git and GitHub
